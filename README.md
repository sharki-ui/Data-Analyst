# Analyst OS · 分析师训练场

一个桌面优先的零后端 Web App 原型。学习者在一份虚构的 Sales Ops 任务中，依次完成问题定义、指标口径、数据体检、预测验算、AI 草稿审计和管理建议。

## 启动

需要 Node.js 18 或以上版本：

```bash
npm run serve
```

然后打开终端显示的本地地址。建议使用宽度至少 1100px 的浏览器窗口。

验证固定数据与核心规则：

```bash
npm run check
node scripts/check.js
```

## 已实现

- 13 条固定 CRM 数据，以及与 PRD 一致的 `$430K Actual / $982K Forecast / $218K Shortfall`
- 五步工作台与七维复盘、步骤解锁、刷新恢复和一键重置
- 公式与范围校验、表格筛选/搜索/排序、五类数据质量证据
- 三项手工复算、三笔优先机会、错误 AI 草稿审计
- Memo 实时检查、规则评分、分级 AI 教练提示和本地自动保存
- 窄屏提交提示、基础键盘操作与状态 Toast

## 原型限制

AI 教练为可重复的规则驱动反馈，不调用真实模型；数据均为虚构且不能上传；进度只保存在当前浏览器设备；首版不提供账号、云同步、多人协作或移动端正式提交。
